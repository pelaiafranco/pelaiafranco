## Control de calidad hecho
- 2.400+ fórmulas recalculadas con LibreOffice: **0 errores**.
- Resultados verificados a mano: cuota, DSCR, préstamo máximo, la fórmula cerrada del precio máximo en el BRRRR, el waterfall (cada dólar asignado, el control da $0) y el interés Dutch vs. non-Dutch.
- Las imágenes muestran los números reales que calcula cada planilla.
- ⚠ **Pendiente (5 min):** abrir cada archivo una vez en Excel y otra en Google Sheets antes de publicar. Lo probé en LibreOffice; solo usa funciones estándar (PMT, PV, IRR, INDEX/MATCH, SUMIFS, SUMPRODUCT), pero conviene confirmarlo en las dos apps.

## Cómo publicar (lo que hacés vos)
**Etsy** (unos 5 min por producto): Shop Manager → Listings → Add a listing → subir las 5 imágenes en orden → pegar el título, la descripción y los tags de `LISTING.md` → "Digital" → subir el `.xlsx` → precio → Publish.
- Etsy exige que el vendedor diseñe sus productos; se permite usar IA como herramienta. Vos aprobás el diseño y el criterio financiero, así que declaralo como diseño tuyo.

**Gumroad** (unos 3 min por producto): New product → Digital product → nombre y precio → subir el `.xlsx` → pegar la descripción → imágenes de portada → Publish.
